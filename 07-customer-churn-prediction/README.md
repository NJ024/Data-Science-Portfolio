# Customer Churn Prediction

Classification pipeline flagging telecom accounts likely to cancel, using contract type,
tenure, billing, and service features. Compares Logistic Regression against a Random Forest,
evaluated with a confusion matrix and ROC-AUC. The trained model is saved and reused by the
Streamlit app in `../09-churn-streamlit-app`.

## Why this project
Churn prediction is one of the most common applied-ML problems in industry, and it's a natural
fit for a deployment follow-up (see project 09) — the difference between a notebook result and
something a business team can actually click on.

## Data
`data/telecom_churn.csv` — 3,000 synthetic telecom customers, with churn probability driven by
contract type, tenure, internet service, tech support, and payment method — modeled after
patterns commonly seen in real telecom churn datasets.

## Files
| File | Purpose |
|---|---|
| `notebook.ipynb` | Encoding → Logistic Regression → Random Forest → confusion matrix → ROC curve → feature importance → business recommendations → saves `model.pkl` |
| `data/telecom_churn.csv` | Synthetic churn data |
| `model.pkl` | Trained Random Forest + scaler + encoders (generated by running the notebook) |

## How to run
```bash
pip install -r requirements.txt
jupyter notebook notebook.ipynb
```
Running the notebook end-to-end also copies `model.pkl` into `../09-churn-streamlit-app/model/`
so the Streamlit app has a live model to serve.

## Approach
1. Label-encoded categorical features, stratified train/test split.
2. Logistic Regression baseline, then a Random Forest with confusion matrix + ROC-AUC.
3. Feature importance translated into three concrete retention actions (see notebook section 6),
   not left as an abstract chart.
4. Model, scaler, and encoders bundled into a single `model.pkl` for reuse in the Streamlit app.

## Findings
`contract_type` and `tenure_months` are the strongest churn predictors — month-to-month
customers in their first year churn the most. See the executed notebook for exact accuracy/
ROC-AUC values and the full confusion matrix.
